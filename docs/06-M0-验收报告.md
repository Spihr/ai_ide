## 三、关键设计落点

1. **策略闸门在 main，不在 preload**。preload 只做能力收窄，真正的放行判定集中在 `main/policy.ts`；M0 白名单只有 `core.ping` / `core.stats`，`core.hello` / `core.shutdown` 不对 UI 开放，`$/` 前缀的保留方法永远拒绝。已由单测钉死。
2. **类型单向流动**：Rust 是协议的唯一真相源，TS 侧 `generated/` 全部由 `pnpm types:gen` 产出。CI 会在重新生成后执行 `git diff --exit-code`，手改生成物或忘记同步都会红。
3. **内核崩溃不阻断 UI**：`startCore()` 失败只把状态置为 `failed` 并推给渲染进程，窗口照常显示，错误看得见。
