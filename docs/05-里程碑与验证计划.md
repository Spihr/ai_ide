# 里程碑与验证计划

> 文档版本：v0.1（待审阅）
> 原则：**每个里程碑必须产出可运行、可验证的东西**，不允许"只写代码不验收"。

---

## 1. 里程碑总览

| 里程碑 | 主题 | 交付物 | 验收标准（硬指标） |
|---|---|---|---|
| M0 | 骨架与通信 | Monorepo 脚手架、Electron 空壳、Rust 内核空壳、握手打通 | 应用启动 3s 内可交互；`core.hello` 成功；`core.ping` RTT < 5ms；CI 绿 |
| M1 | 编辑器壳 | 工作区打开、文件树、Monaco 多标签、保存、搜索 | 打开 1 万文件工作区 < 3s；编辑 1 万行文件输入 < 16ms；保存后磁盘内容一致 |
| M2 | 模型接入 | Provider 配置 UI、密钥加密、流式对话 | 首个 Provider 连接测试通过；流式首 token < 2s；密钥明文不出现在任何文件中（可验证） |
| M3 | 上下文引用 | `@文件/@文件夹/@选区/@当前文件`、token 计数、压缩 | 引用 5 个文件时正确注入且 token 计数误差 < 3%；超限自动压缩不报错 |
| M4 | Agent 闭环 | 6 个核心工具、权限审批、diff 预览与应用 | 完成"找到函数→改超时→跑测试"端到端任务；`edit_file` 唯一匹配失败时自动重试成功 |
| M5 | 持久化与治理 | 会话 SQLite、导出、审计日志、检查点回滚 | 重启后会话完整恢复；回滚可精确还原文件字节；审计记录完整 |
| M6 | 终端与 Git | xterm.js 终端、Git 状态与 diff | 终端交互无卡顿、resize 正确；Git 面板能显示变更并提交 |
| M7 | MCP | stdio + HTTP 双传输、工具注入 | 连接 2 个官方 MCP Server 并成功调用其工具 |
| M8 | 打包分发 | electron-builder 安装包（含 Rust 二进制） | 干净 Windows 机器上安装即用；无缺失运行库 |

**P2 备选（视进度）**：Inline Edit（Ctrl+K）、Tab 补全、LSP、向量检索、多模态输入。

## 4. 风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 各家 API 工具调用协议差异大 | Agent 在部分厂商上不可用 | Provider 归一化层 + 用"仅文本模式"降级（无工具调用时退化为 Chat） |

| Rust 与 TS 类型漂移 | 隐性 bug | protocol crate 单一来源 + CI 校验生成物无 diff |
| 命令执行安全 | 误删数据 | 双闸门 + 黑名单 + 回收站 + 工作区边界 + 超时 |
